runtime governance · Jan 2026–present

Vorion — BASIS & CogniGate

~8ms p50 / ~20ms p95 policy decisions (same-region)

A vendor-neutral governance layer for agentic AI. BASIS is the open trust-tier specification (T0–T7); CogniGate is the Apache-2.0 policy-enforcement engine that checks every agent tool-call against it and writes an auditable decision record. Around it: AgentAnchor (a public trust registry), Aurais (a fleet security console with anomaly detection and quarantine-on-click), and Rainbow (a live trust-analytics observatory). open source · agent memory

agent-memory-service

100% current-fact accuracy · 0% stale · ~35% token savings

A typed 4-store memory layer for LLM agents — working, episodic, semantic, procedural — with episodic→semantic consolidation and supersession-based forgetting, so a fact that changes mid-conversation stops answering with the stale value. A 4-config ablation, evaluated on a controlled synthetic set and the LoCoMo-10 benchmark, reproduces every number from a clean clone.

Python FAISS Live on Cloud Run
github.com/axiom-orion/agent-memory-service
open source · retrieval

genealogy-graphrag

relational recall@5 0.000 → 1.000

Hybrid retrieval (BM25 + dense) with cross-encoder reranking, plus a typed kinship-graph resolver for questions whose answer entity is never named in the query — the structural blind spot of dense and lexical retrieval alone. Dual graph backend: in-memory NetworkX for zero-setup eval, Neo4j/Cypher for production traversal.

Python Neo4j Reranking

open source · policy demo

governed-agents

Full NDJSON audit trail

A Next.js runtime that wraps LLM calls in a named-rule policy gate — every tool call evaluated against a rule set before execution, decisions emitted as TraceEvents for a replayable audit trail. Multi-model consensus across Claude, Gemini, and Grok, with a Red Cell adversarial mode that stress-tests policy coverage.
